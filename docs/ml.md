# YandexGPT API в DataSphere

## Задание на семинарах 24.03-31.03

1. Скачайте блокнот для работы c yandex-gpt-api.
2. Создайте проект в Yandex DataSphere.
3. Поместите блокнот в проекте и пройдите по инструкции в блокноте по подключению к API.
4. Составьте запрос для модели и сохраните ответ.
